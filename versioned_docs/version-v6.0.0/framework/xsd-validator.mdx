:::note[motivation]
XSD validation is a required step when handling XML files in Logic App workflows. [Microsoft only supports XSD validation within workflows on top of **Azure Integration Accounts**](https://learn.microsoft.com/en-us/azure/logic-apps/logic-apps-enterprise-integration-schemas?tabs=consumption). This resource is expensive and not always available within project budgets.

The Invictus Framework includes a **XSD Validator** component that validates XML files within your workflow via a HTTP endpoint. By storing XSD schemas in an Azure Blob Storage container, project teams can limit the costs.
:::

<Collapsible number={<FontAwesomeIcon icon={faCircleCheck} />} title="XSD validate user XML">

The **XSD Validator** has a single endpoint available to run validations. Passing an input content and the name of a stored schema, the component responds with the validation result. The component looks up XSD schemas in the `xsdvalidatorstore` Azure Blob Storage container.

{/* vale off */}
<ApiPlayground
  method="POST"
  path="/api/ValidateXmlAgainstXsd"
  description="Validates a Base64-encoded XML document against a named XSD schema, stored in Azure Blob Storage. Returns whether the XML is valid and lists any schema violations found."

      name: "content",

    xsdName: "person.xsd"

  responses={[
    {
      status: 200,

    {
