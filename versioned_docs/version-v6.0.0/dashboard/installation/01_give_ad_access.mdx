# <BadgedText badge={<OnlyAdminsBadge/>}>Give Invictus access to your Microsoft Entra ID</BadgedText>
To use your Microsoft Entra ID groups as a way of authentication and flow authorization, follow these steps.

{/* vale Google.WordListCase = NO */}
<Walkthrough>
  <Collapsible title="Register an Application for Invictus">
    <em>[ <FontAwesomeIcon icon={faLink} /> Microsoft Docs: register an app](https://learn.microsoft.com/Entra/identity-platform/quickstart-register-app?tabs=certificate%2Cexpose-a-web-api)</em>

    * Choose the <strong>multi-tenant</strong> account type option to let Invictus use the app registration.
    * Add <strong>Redirect URI's</strong> to your Invictus pages:
      * `https://your-invictusdashboard.azurewebsites.net/login`
      * `https://your-invictusdashboard.azurewebsites.net/api/auth/callback/azure-ad`
    * Check the **<FontAwesomeIcon icon={faSquareCheck} /> Access tokens** box ([why?](https://learn.microsoft.com/entra/identity-platform/v2-oauth2-implicit-grant-flow?WT.mc_id=Portal-Microsoft_AAD_RegisteredApps))
    * Add a new <strong>client secret</strong> (copy the value for later use).
    * Linked Enterprise Application:
      * Assign <strong>Owners</strong> ([more info](https://learn.microsoft.com/entra/identity/enterprise-apps/assign-app-owners?pivots=portal))
      * Grant <strong>Admin consent</strong> ([more info](https://learn.microsoft.com/entra/identity/enterprise-apps/grant-admin-consent?pivots=portal))
  </Collapsible>

  <Collapsible title="Expose an API with scoped permissions">
    <em>[ <FontAwesomeIcon icon={faLink} /> Microsoft Docs: expose an API](https://learn.microsoft.com/Entra/identity-platform/quickstart-configure-app-expose-web-apis#add-a-scope)</em>

    * Use the default <strong>Application ID URI</strong> (copy it).
    * Add a scope with <strong>Admin and users</strong> consent.
    * Use this name for the scope: `access_as_user`
  </Collapsible>

  <Collapsible title="Add API permissions">
    <em>[ <FontAwesomeIcon icon={faLink} /> Microsoft Docs: configure API permissions](https://learn.microsoft.com/Entra/identity-platform/quickstart-configure-app-access-web-apis)</em>
    * **Microsoft Graph**
      * ```Directory.Read.All```: **Delegated**
      * ```User.Read```: **Delegated**
      * ```User.Read.All```: **Delegated** + **Application**
      * ```Group.Read.All```: **Application**
      * ```Mail.Send```: **Application**
      
{/* vale Microsoft.FirstPerson = NO */}   
    * **My APIs**
{/* vale Microsoft.FirstPerson = YES */}
      * The `access_as_user` scope you created earlier: **Delegated**
  </Collapsible>


  <Collapsible title="Pass App Registration values to Invictus deployment">
    * `azureActiveDirectoryClientId` <FontAwesomeIcon icon={faArrowRight} /> from **App Registration <FontAwesomeIcon icon={faChevronRight} /> Overview**
    * `azureActiveDirectoryTenantId` <FontAwesomeIcon icon={faArrowRight} /> from **App Registration <FontAwesomeIcon icon={faChevronRight} /> Overview**
    * `azureActiveDirectoryClientSecret` <FontAwesomeIcon icon={faArrowRight} /> the one you copied earlier
    * `azureActiveDirectoryAudience` <FontAwesomeIcon icon={faArrowRight} /> the default **Application ID URI**
  </Collapsible>
</Walkthrough>

## Sync your Microsoft Entra ID groups to Invictus
<Breadcrumb paths={[`Groups`, `Sync all groups`]} />

The Dashboard uses the groups in your Microsoft Entra ID to verify whether users can access flows. (See [flow permissions](../flows/01_add.mdx#flow-permissions)).

* [Add Microsoft Entra ID group](https://learn.microsoft.com/en-us/entra/fundamentals/how-to-manage-groups)
* [Add Microsoft Entra ID user](https://learn.microsoft.com/en-us/entra/fundamentals/how-to-create-delete-users)

:::warning
The Dashboard only syncs groups of active users (Entra ID users that already have signed in into the Dashboard).
:::

## Enable only required groups
<Breadcrumb items={[`Groups`, <em>your group</em>, <FontAwesomeIcon icon={faCirclePause} aria-label='pause' />]} />

For security reasons, only enable the groups that you want to use for [flow permissions](../flows/01_add.mdx#flow-permissions). 'Enabled' is the default state. Deactivate groups by selecting the <FontAwesomeIcon icon={faCirclePause} aria-label='pause' /> icon next to the group name.

## Assign user role to required groups
<Breadcrumb items={[`Groups`, <em>your group</em>, <FontAwesomeIcon icon={faUser} aria-label='user' />]} />

The user role permission describes what authority each member of the group has throughout the Dashboard, [more info on Dashboard roles](../security/03_roles.mdx).
Assign a user role by selecting the <FontAwesomeIcon icon={faUser} aria-label='user' /> icon next to the group name and picking the desired <DropDownInput label="User role" />.
