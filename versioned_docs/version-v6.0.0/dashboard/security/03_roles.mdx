# Control the access to your flows
## Flow permissions
{/* vale Google.WordList = NO */}
Each row in this table shows what a user can do in a folder. A folder has three roles. *Reader* can view the flows. *Operator* can view and run them. *Folder admin* can do all the actions in this table. You can add both **local users** and **Entra ID groups** to a folder.

<AllowIcon aria-hidden="true" /> Allowed &nbsp;&nbsp; <DisallowIcon aria-hidden="true" /> Not allowed
|          |                            | Reader | Operator | Folder admin | Description                                                                                                                                                           |
| -------- | -------------------------- | :----: | :------: | :----------: | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Flow     | View **flow** status     |    <AllowIcon/>   |    <AllowIcon/>     |      <AllowIcon/>       | See the [status of all flows](../flows/index.mdx) on the home page.                                                      |
| <SROnly>Flow</SROnly> | Resubmit/Resume **flow**   |   <DisallowIcon/>    |    <AllowIcon/>     |      <AllowIcon/>       | Run actions on the flow like [<Button label="Resubmit" icon={faArrowRotateLeft} />/<Button label="Resume" icon={faCirclePlay} />/<Button label="Ignore" icon={faEyeSlash} />](../flows/04_import-flow-traces/import-flows-via-la.mdx). |
| <SROnly>Flow</SROnly> | Add **flow**               |   <DisallowIcon/>    |    <DisallowIcon/>     |      <AllowIcon/>       | [<Button icon={faPlus} label="Create a new flow"/>](../flows/01_add.mdx) in a folder, possibly with alerts.                                                                                            |
| <SROnly>Flow</SROnly> | Edit **flow**              |   <DisallowIcon/>    |    <DisallowIcon/>     |      <AllowIcon/>       | [<Button icon={faPenToSquare} label="Edit flow"/>](../flows/01_add.mdx)'s mapping, properties, alerts.                                                                                                  |
| <SROnly>Flow</SROnly> | Delete **flow**            |   <DisallowIcon/>    |    <DisallowIcon/>     |      <AllowIcon/>       | [<Button icon={faTrashCan} label="Delete flow"/>](../flows/01_add.mdx) from a folder.                                                                                                                                         |
| Messages | View **messages**          |   <AllowIcon/>    |    <AllowIcon/>     |      <AllowIcon/>       | [<Button icon={faMagnifyingGlass} label="Search"/>](../flows/02_search.mdx) for messages passing through a flow.                                                                           |
| Folder   | View **folders**           |   <AllowIcon/>    |    <AllowIcon/>     |      <AllowIcon/>       | See all folders and their flows on the home page.                                                                                                  |
| <SROnly>Folder</SROnly> | Edit **folder**            |   <DisallowIcon/>   |    <DisallowIcon/>     |      <DisallowIcon/>       | [<Button icon={faPenToSquare} label="Edit folder"/>](../flows/01_add.mdx)'s name and its place in the list.                                                                                                                  |
| <SROnly>Folder</SROnly> | Grant **flow** permissions |   <DisallowIcon/>    |    <DisallowIcon/>     |      <DisallowIcon/>       | [<Button icon={faUserGroup} label="Edit folder permissions"/>](../flows/01_add.mdx#flow-permissions) to set who can use the flows in a folder.                                                     |
| <SROnly>Folder</SROnly> | Delete **folder**          |   <DisallowIcon/>    |    <DisallowIcon/>     |      <DisallowIcon/>       | [<Button icon={faTrashCan} label="Delete folder"/>](../flows/01_add.mdx) and all its flows and sub-folders.                                                                             |

:::info[System admins]
A user with the *System admin* role can do all of the same things as a *Folder admin* on all flows in all folders. You do not need to add them to a folder first. They can use all flows in all folders in the Dashboard.
:::

## User roles
The next table shows what each user can do in the rest of the Dashboard. Each user has one of two roles. *Non-admin* can use some parts of the Dashboard. *System admin* can use all of it. Entra ID users get their role from their group. Local users each get their own role.

<AllowIcon aria-hidden="true" /> Allowed &nbsp;&nbsp; <DisallowIcon aria-hidden="true" /> Not allowed
|          |                                 | Non-admin | System admin | Description                                                                                                                                                                                    |
| -------- | ------------------------------- | :-------: | :----------: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Users    | View **users**                  |     <DisallowIcon/>     |      <AllowIcon/>       | Go to the [<UsersTab />](./01_users.mdx) page to see all **local** and **Entra ID** users.                                                                                                                  |
| <SROnly>Users</SROnly> | Add **local user**              |     <DisallowIcon/>     |      <AllowIcon/>       | [<Button icon={faPlus} label="Add a new user"/>](./01_users.mdx) with a username and password. |
| <SROnly>Users</SROnly> | Add **Microsoft Entra ID user** |     <AllowIcon />     |      <AllowIcon />       | Use [<SignInWithMicrosoftButton />](../installation/01_give_ad_access.mdx) to sign in and add the user. They must be in a [synced group](../installation/01_give_ad_access.mdx). |
| <SROnly>Users</SROnly> | Edit **local user** role        |     <DisallowIcon/>     |      <AllowIcon/>       | [<Button icon={faPencil} label="Edit role"/>](./01_users.mdx) of **local** users. **Entra ID** users get their role from their **group**.                                                                                          |
| <SROnly>Users</SROnly> | Delete **user**                 |     <DisallowIcon/>     |      <AllowIcon/>       | [<Button icon={faTrashCan} label="Delete user"/>](./01_users.mdx) from the Dashboard. For Entra ID users, also remove them from their synced groups. |
| Groups   | View **groups**                 |     <DisallowIcon/>     |      <AllowIcon/>       | Go to the [<GroupsTab />](./01_users.mdx) page to see all synced groups.                                                                                                                                    |
| <SROnly>Groups</SROnly> | Sync **groups**                 |     <DisallowIcon/>     |      <AllowIcon/>       | Run the [<Button label="Sync all groups" />](../installation/01_give_ad_access.mdx#sync-your-microsoft-entra-id-groups-to-invictus-) action to sync all groups now.                                                                                                             |
| <SROnly>Groups</SROnly> | Disable **group**               |     <DisallowIcon/>     |      <AllowIcon/>       | [<Button icon={faCirclePause} label="Disable group" />](../installation/01_give_ad_access.mdx) to stop its members from seeing the flows.                                                                                            |
| <SROnly>Groups</SROnly> | Edit **group** role             |     <DisallowIcon/>     |      <AllowIcon/>       | [<Button icon={faUserShield} label="Edit role" />](../installation/01_give_ad_access.mdx#assign-user-role-to-required-groups-) of a group to set what it can do in the flows.                                                                                                              |
| <SROnly>Groups</SROnly> | Delete **group**                |     <DisallowIcon/>     |      <AllowIcon/>       | [<Button icon={faTrashCan} label="Delete group" />](../installation/01_give_ad_access.mdx)'s flow access. If its Entra ID users are still in the Dashboard, the group syncs back in on their next sign-in. |
| Settings | View **settings**               |     <AllowIcon/>     |      <AllowIcon/>       | Go to the [<SettingsTab />](../settings.mdx) page to see the current Dashboard settings.                                                                                                          |
| <SROnly>Settings</SROnly> | Edit **settings**               |     <DisallowIcon/>     |      <AllowIcon/>       | Go to the [<SettingsTab />](../settings.mdx) page to change the Dashboard settings.                                                                                                                                             |
| Audits   | View **audits**                 |     <DisallowIcon/>     |      <AllowIcon/>       | Go to the [<AuditsTab />](../security/04_auditing.mdx) page to see all the logs.                                                                                                   |
