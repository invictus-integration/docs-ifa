# <BadgedText badge={<OnlyAdminsBadge/>}>Manage Users in the Dashboard</BadgedText>
<Breadcrumb paths={["Users"]} summary="From the Dashboard's main navigation, focus on the **Users** tab" />

Users can sign in to the Dashboard with a **local** or their **Microsoft Entra ID** account. Prefer the latter for better security.

![users overview](/images/v2_users1.png)

<Tabs groupId="user-type" queryString>
<TabItem value="entra-id" label="Entra ID" default>

<Admonition icon={<FontAwesomeIcon icon={faUser} aria-hidden="true" />} type="warning" title="Microsoft Entra ID sign-ins">
Microsoft Entra ID sign-ins require a **synced group** (see [syncing groups](../installation/01_give_ad_access.mdx#sync-your-microsoft-entra-id-groups-to-invictus) to set them up) and a [role assigned](./03_roles.mdx).
</Admonition>

<details>
<summary><span id="add-an-entra-id-user">**Add an Entra ID account**</span></summary>

Entra ID accounts sign in with the **<FontAwesomeIcon icon={faMicrosoft} aria-hidden="true" /> Sign in with Microsoft** button. This adds them to the Dashboard.
Make sure they're a member of a [synced group](../installation/01_give_ad_access.mdx#sync-your-microsoft-entra-id-groups-to-invictus) that has a [role assigned](./03_roles.mdx).

</details>

<details>
<summary>**Delete an Entra ID account**</summary>

Select an account from the list. Focus on the **<FontAwesomeIcon icon={faTrashCan} aria-label="trash can" /> delete button** to remove it. This doesn't delete the account in Entra ID.

</details>

<details>
<summary><span id="edit-an-entra-id-accounts-role">**Edit an Entra ID account's role**</span></summary>

Entra ID accounts have no direct role. Their group membership determines their role.
[If the group can access a flow](../installation/01_give_ad_access.mdx#sync-your-microsoft-entra-id-groups-to-invictus), so can the user.

</details>

<details>
<summary>**Send forgot password mails**</summary>

You can make the Dashboard send out forgot password mails to Entra ID users.
* [create an Entra ID app](https://learn.microsoft.com/en-us/entra/identity-platform/quickstart-register-app).
* Add the [`Mail.Send` permission](../installation/01_give_ad_access.mdx). OAuth 2.0 uses it to send emails.
* Go to <Breadcrumb items={[<><FontAwesomeIcon icon={faSlidersH} aria-label='Slider icon' /></>, `Settings`]} summary="From the Dashboard's main navigation, focus on your **slider icon** button, then select **Settings** from the pop-up menu" /> to add the backup email address for 'Forgot password' emails.

:::warning
The Dashboard may use any email in the tenant as the sender.
:::

</details>

</TabItem>
<TabItem value="local" label="Local">

You can create a local, isolated account from within the Dashboard. You can assign roles and delete them at any time.

<details>
<summary>**Add a local account**</summary>

<Breadcrumb items={[<><FontAwesomeIcon icon={faUser} aria-label='Users' /> Users</>, <><FontAwesomeIcon icon={faPlus} aria-label="Plus icon" /> Add a new user</>]} summary="From the Dashboard's main navigation, focus on the **Users** tab, then focus on the **Add a new user** button" /> 
* Fill in the <TextInput label="Username" />, <TextInput label="Email" /> and <TextInput label="Password" /> fields.
* Assign a <DropDownInput label="Role" /> to set flow access. See [available roles](./03_roles.mdx) for more information.

</details>

<details>
<summary>**Delete a local account**</summary>

Select an account from the list. Focus on the **<FontAwesomeIcon icon={faTrashCan} aria-label='Trash can icon' /> delete button** to remove it.

<Admonition icon={<FontAwesomeIcon icon={faMagnifyingGlass} /> } type="tip" title="Distinguish local accounts">
Local accounts always have their own role.
</Admonition>

</details>

<details>
<summary>**Edit a local account's role**</summary>

Select an account from the list. Focus on the **<FontAwesomeIcon icon={faPencil} aria-label='Pencil icon' /> button** to edit its <DropDownInput label="Role" />. See [available roles](./03_roles.mdx) for more information.
</details>

<details>
<summary>**Send forgot password mails**</summary>

The Dashboard can email local accounts a password reset link. This needs an email server, set up in **Settings**.

<Breadcrumb items={[<><FontAwesomeIcon icon={faSlidersH} aria-label='Slider icon' /></>, `Settings`]} summary="From the Dashboard's main navigation, focus on your **slider icon** button, then select **Settings** from the pop-up menu" />

| Forgot password setting  | Description                                                                                                                                                      |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <TextInput label="Host" />                   | The host address of the email server. For example: `"smtp.gmail.com"` for Gmail. |
| <NumberInput label="Port number" />            | The email server port. Default is `587`.                                                                |
| <TextInput label="Email key vault key" />    | The Key Vault secret name for the sender email address (bundled with Invictus).         |
| <TextInput label="Password key vault key" /> | The Key Vault secret name for the sender email password (bundled with Invictus).        |
| <ToggleInput label="Enable SSL" />            | Enable SSL. Most email providers require it.                                                                             |
  
</details>

</TabItem>
