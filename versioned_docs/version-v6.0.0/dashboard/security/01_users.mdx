# <BadgedText badge={<OnlyAdminsBadge/>}>Manage Users in the Dashboard</BadgedText>
<Breadcrumb paths={["Users"]} />

Two user types can access the Dashboard. Invictus manages **Local** users. Your tenant manages **Microsoft Entra ID** users.

:::praise[recommended]
Prefer **Entra ID** users for security.
:::

![users overview](/images/v2_users1.png)

<Tabs groupId="user-type" queryString>
<TabItem value="entra-id" label="Entra ID" default>

> <FontAwesomeIcon icon={faUser} /> Requires a [synced Entra ID group](../installation/01_give_ad_access.mdx#sync-your-microsoft-entra-id-groups-to-invictus-).

The Dashboard works with users in Entra ID groups.
See [syncing groups](../installation/01_give_ad_access.mdx) to set them up.

<details>
<summary><span id="add-an-entra-id-user">**Add an Entra ID user**</span></summary>

Entra ID users sign in with the [<SignInWithMicrosoftButton />](../installation/01_give_ad_access.mdx) button. They must be part of a [synced group](../installation/01_give_ad_access.mdx#sync-your-microsoft-entra-id-groups-to-invictus-).

:::warning[requires role]
Make sure the group has a [role assigned](./03_roles.mdx). Without one, the Dashboard won't work.
:::

</details>

<details>
<summary>**Delete an Entra ID user**</summary>

Click the delete icon <FontAwesomeIcon icon={faTrashCan} /> to remove a user from the Dashboard. This action doesn't remove them from Entra ID.

<Admonition icon={<FontAwesomeIcon icon={faMagnifyingGlass} /> } type="tip" title="Distinguish Entra ID users">
Entra ID users have no direct role. They get their role from their group.
</Admonition>
</details>

<details>
<summary>**Edit an Entra ID user's role**</summary>

Entra ID users have no direct role. They get their role from their group.
[If the group can access a flow](../installation/01_give_ad_access.mdx#sync-your-microsoft-entra-id-groups-to-invictus-), so can the user.

</details>

<details>
<summary>**Configure forgot password procedure**</summary>

To use forgot password, create an Entra ID app. Add the [`Mail.Send` permission](../installation/01_give_ad_access.mdx). OAuth 2.0 uses it to send emails.

Go to <Breadcrumb items={[<><em>profile name</em>&nbsp;<FontAwesomeIcon icon={faSlidersH} /></>, "Settings"]} /> to add the backup email address for 'Forgot password' emails.

:::warning
The Dashboard may use any email in the tenant as the sender.
:::

</details>

</TabItem>
<TabItem value="local" label="Local">

The Dashboard manages local users. You can assign roles and delete them at any time.

<details>
<summary>**Add a local user**</summary>

Go to <Breadcrumb items={[<><FontAwesomeIcon icon={faUser} /> Users</>, <><Button icon={faPlus} label="Add a new user" /></>]} /> 
* Fill in the <TextInput label="Username" />, <TextInput label="Email" /> and <TextInput label="Password" /> fields.
* Assign a [<DropDownInput label="Role" />](./03_roles.mdx) to set flow access.

</details>

<details>
<summary>**Delete a local user**</summary>

Click the delete icon <FontAwesomeIcon icon={faTrashCan} /> to remove a user.

<Admonition icon={<FontAwesomeIcon icon={faMagnifyingGlass} /> } type="tip" title="Distinguish local users">
Local users have a direct role assigned.
</Admonition>

</details>

<details>
<summary>**Edit a local user's role**</summary>

Click the <FontAwesomeIcon icon={faPencil} /> icon to edit a local user's [<DropDownInput label="Role" />](./03_roles.mdx).
</details>

<details>
<summary>**Configure forgot password procedure**</summary>

Set up the email server for password resets.

Go to <Breadcrumb items={[<><em>profile name</em>&nbsp;<FontAwesomeIcon icon={faSlidersH} /></>, `Settings`]} />

| Forgot password setting  | Description                                                                                                                                                      |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <TextInput label="Host" />                   | The host address of the email server. For example: `"smtp.gmail.com"` for Gmail. |
| <NumberInput label="Port number" />            | The email server port. Default is `587`.                                                                |
| <TextInput label="Email key vault key" />    | The Key Vault secret name for the sender email address (bundled with Invictus).         |
| <TextInput label="Password key vault key" /> | The Key Vault secret name for the sender email password (bundled with Invictus).        |
| <ToggleInput label="Enable SSL" />            | Enable SSL. Most email providers require it.                                                                             |
  
</details>

</TabItem>
