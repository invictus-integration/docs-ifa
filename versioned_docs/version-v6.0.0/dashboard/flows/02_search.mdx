# Search for messages in a flow
<Breadcrumb paths={[`Your Flows`, <><FontAwesomeIcon icon={faArrowPointer} /> Select a flow</>]} />

Search for messages in a flow to find defects or check your integrations.
Select one or more flows from the <DropDownInput label="Select Flows" /> to start.

![Pick flows from selection](/images/v2_search-advanced3.png)

<Tabs groupId="search-type">
<TabItem value="basic" label="Basic search" default>
Use the top <TextInput label="Search" icon={faMagnifyingGlass} /> box to filter messages by property.

![Basic search example](/images/dashboard/search-for-flow-traces-basic-search.gif)

| Message property | Description                                                                                                                                                                                                                                                                                                                   |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Chain ID**        | (= transaction ID). Also known as the 'client tracking ID' in Azure Logic Apps.                                                                                                                                                                        |
| **DSAV**            | **Domain**, **Service**, **Action**, **Version** business properties. |

</TabItem>
<TabItem value="advanced" label="Advanced search">
Open the <span style={TableHeaderStyle}>Advanced Search <FontAwesomeIcon icon={faAngleDown} /></span> pane to add more filters to your query.

![Advanced search example](/images/dashboard/search-for-flow-traces-advanced-search.gif)

| Filter           | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Status**       | Messages at a given state:<br/><br/> <ul style={NoListStyle}><li><CheckBoxInput label="Active" checked={true} /> (= messages in progress, [resubmit & resume included](./04_import-flow-traces/import-flows-via-la.mdx))</li><li><CheckBoxInput label="Completed" /> (= messages done)</li><li><CheckBoxInput label="Error" /> (= failed messages, [including Azure Logic Apps](./04_import-flow-traces/import-flows-via-la.mdx))</li><li><CheckBoxInput label="Ignored" /> (= messages ignored by users)</li><li><CheckBoxInput label="Cancelled" /> <BadgedText badge={<NewSinceBadge version="v6.2" />} variant='background'>(= messages cancelled by users)</BadgedText></li></ul>                       |
| **Date filter**  | Messages in a given time frame:<br/><br/> <ul style={NoListStyle}><li><FontAwesomeIcon icon={faCircleDot} /> All dates (= last 30 days)</li><li><FontAwesomeIcon icon={faCircle} /> After <DateInput /></li><li><FontAwesomeIcon icon={faCircle} /> Before <DateInput /></li><li><FontAwesomeIcon icon={faCircle} /> Between <DateInput /> and <DateInput /></li><li><FontAwesomeIcon icon={faCircle} /> Last <TextInput label="amount" /> <DropDownInput label="time period" /></li></ul>                                                                                                                                                                                                                                                  |
| **DSAV**         | Filter by mapping fields: <TextInput label="Domain" />, <TextInput label="Service" />, <TextInput label="Action" />, <TextInput label="Version" />. Invictus reads these from Azure Logic App tracking (see [importing via Azure Logic Apps](./04_import-flow-traces/import-flows-via-la.mdx)). Use <CheckBoxInput label="Contains Word" /> for partial matches.                                                                                         |
| **Chain ID**     | Messages with the same Chain ID. In Azure Logic Apps, this is the 'client tracking ID'.                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Properties**   | Filter messages by property: <ul><li><DropDownInput label="your property"/> <DropDownInput label="Equal"/> <TextInput label="your value" /> (= exact match)</li><li><DropDownInput label="your property"/> <DropDownInput label="Not Equal"/> <TextInput label="your value" /> (= exclude matches)</li><li><DropDownInput label="your property"/> <DropDownInput label="Starts With"/> <TextInput label="your value" /> (= prefix match)</li><li><DropDownInput label="your property"/> <DropDownInput label="Ends With"/> <TextInput label="your value" /> (= suffix match)</li><li><DropDownInput label="your property"/> <DropDownInput label="Contains"/> <TextInput label="your value" /> (= partial match)</li><li><DropDownInput label="your property"/> <DropDownInput label="Regex"/> <TextInput label="your value" /> (= pattern match, [learn more](https://learn.microsoft.com/en-us/dotnet/standard/base-types/regular-expression-language-quick-reference))</li></ul> |

</TabItem>
