# Add new flows <OnlyFolderAdminsBadge/>
{/* vale Vale.Spelling = NO */}
<Breadcrumb paths={[`Your Flows`, <><i>your_folder</i> •••</>, <><FontAwesomeIcon icon={faPlus} /> Create New Flow</>]} />
{/* vale Vale.Spelling = YES */}

Create new flows to track your integrations.
With the right mapping, you see each message as it passes through.

| Property                | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Flow Name**           | A <TextInput label="Flow Name" /> for the integration. Example: *invoice request*, *invoice approval*.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Folder**              | The <DropDownInput label="Folder" /> where to save the flow. [See folders structures](./index.mdx#organizing-flows-in-folders).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Mapping**             | Identifies a message in the flow. The <TextInput label="Domain" />, <TextInput label="Service" />, <TextInput label="Action" />, and <TextInput label="Version" /> fields match a message to a flow. Set a <TextInput label="Workflow name" /> if the message ran through an Azure Logic App.                                                                                                                                                                                                          |
| **Business Properties** | Metadata for the flow. Each <TextInput label="Business property name" /> gets its value from the message.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Advanced Settings**   | <ul><li><ToggleInput label="Connected Dashboard" /> (= [hybrid setups](../settings.mdx) require a link from one Dashboard (BizTalk) to another (Azure).)</li><li><ToggleInput label="Show milestone and event text" /> (= displays the flow milestone and event text data).</li><li><ToggleInput label="Show Resubmit / Resume" /> (= make the flow action buttons available per flow <NewSinceBadge version="v6.2" />.)</li><li><ToggleInput label="Custom resubmit URL" /><TextInput label="Your resubmit URL" /> and <ToggleInput label="Custom resume URL" /><TextInput label="Your resume URL" /> (= turn these options on and set the URLs to use [your own resume and resubmit logic](./04_import-flow-traces/import-flows-via-la.mdx).)</li></ul> |
| **Alerts**              | <DetailsLink targetId="flow-alerting">See alerting</DetailsLink>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

<details id="flow-permissions">
<summary><span>**Allow access to flow**</span></summary>

Microsoft Entra ID groups and local users can access flows in the folder.
Users get their flow permissions based on [their role](../security/03_roles.mdx).

{/* vale Vale.Spelling = NO */}
<Breadcrumb paths={[`Your Flows`, <><i>your_folder</i> •••</>, <><FontAwesomeIcon icon={faUserGroup} /> Edit Folder Permissions</>]} />
{/* vale Vale.Spelling = YES */}

:::info[Admins can access all flows]
Users with the *System admin* role can see all flows in every folder.
:::
</details>

<details id="flow-alerting">
<summary><span>**Add an alert for a flow**</span></summary>

{/* vale write-good.TooWordy = NO */}
Create [Azure Monitor alerts](https://learn.microsoft.com/en-us/azure/azure-monitor/alerts/alerts-overview) right from the flow.
Alerts track the health of your flows. You get notified when something needs attention. For example, when a flow goes inactive or starts to fail.
{/* vale write-good.TooWordy = YES */}

:::warning[requires role assignments after installation]
The Dashboard requires [role assignments](../installation/03_give_la_access.md) to add alerts to flows.
:::
